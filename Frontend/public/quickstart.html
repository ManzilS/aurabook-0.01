Get started with AuraBook

A local Python proxy for coding agents, with optional shared cloud memory.

Developer preview: the FullBook source repository is currently private. The install steps below require an authorized source checkout; there is no public package download advertised here. You can try the browser demo without installing the client.

1. Install the client

Requires Python 3.11 or newer. In your FullBook checkout, create a virtual environment and install the Client package:

python -m venv .venv
Windows PowerShell
.\.venv\Scripts\Activate.ps1
python -m pip install ./Client
macOS / Linux
source .venv/bin/activate
python -m pip install ./Client

2. Run the offline demo

aura start --demo

The proxy listens at http://127.0.0.1:8080 by default. Demo mode uses scripted local responses, not paid provider calls. In a second terminal using the same environment:

aura status
aura audit --text "Contact developer@example.com"

The audit command previews the client's redaction without uploading the supplied text.

3. Connect a real provider

Stop the demo with Ctrl+C. Create a .env in the directory where you run AuraBook. Use your provider key locally and keep this file out of source control.

AURABOOK_DEMO_MODE=false
AURABOOK_CLOUD_ENABLED=false
AURABOOK_UPSTREAM_BASE_URL=https://api.openai.com/v1
AURABOOK_UPSTREAM_API_KEY=YOUR_PROVIDER_KEY
aura start

Configure an OpenAI-compatible agent to use http://127.0.0.1:8080/v1 as its base URL and select a model available to your provider account. Provider requests incur the provider's usual charges.

Cloud sharing is disabled in this example. Shared memory requires a configured backend and an administrator-issued signing secret. Do not place a shared secret or Supabase service-role key in browser code.

What leaves your machine?

  1. Proxy and redact: the local client captures the debugging context and scrubs recognized sensitive patterns before sharing a trajectory. Review with aura audit; redaction can miss sensitive data.
  2. Distill: when uploads are enabled, the backend receives the scrubbed trace and uses a model to produce a reusable note.
  3. Inject: relevant stored notes are retrieved and added to later agent requests.

The hosted live demo is a different path: your key and prompt travel over HTTPS to AuraBook's backend and then the provider. The key is not written to the demo database. It is retained in session storage, or local storage if you choose Remember. Python snippets execute in your browser through Pyodide and require JavaScript.
